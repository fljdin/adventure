# C23 Conventions

## Project structure

- **src/**: Core game logic (C23, `-Wall -Wextra -Werror`)
  - `main.c`: Entry point
  - `entity.[ch]`: Player/NPC state (health, inventory, strength, dexterity)
  - `inventory.[ch]`: Item management (dynamic array of `struct item`)
  - `dungeon.[ch]`: Room/navigation graph
  - `dice.[ch]`: Roll mechanics (d20, d100, etc.)
- **test/**: Unity test framework (auto-generates runners from test files)
  - Suites in `test_*.c` files
  - No manual runner; Meson processes test files via `unity_gen_runner.process()`

## Coding rules

- Use `-std=c23` (not C11)
- `bool` built-in; no `stdbool.h`
- Use `unsigned` instead of `size_t` or `unsigned int`
- Right-const: `char const *name` not `const char *name`
- Structs named `struct entity`, not typedef'd
- Struct initialization: call `entity_init()`, not malloc inline
- Designated initializers required for all `struct item` literals; positional initializers are forbidden
